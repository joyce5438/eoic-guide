기업 운영 및 혁신 주기 분석

ZIP 파일에서 첫 분석 보고서까지.

여러 분기의 재무제표와 실적 발표를 통해 혁신의 가속, 둔화, 수익화 지연과 회복을 판단합니다. 매출 성장과 높은 이익률만으로 혁신의 성공을 판단하지 않습니다.

설치 시작 ↗

ZIP은 Austin이 비공개 그룹에서 제공합니다. 이 페이지에는 다운로드가 없습니다.

01

제공되는 분석

  • 전체 운영과 각 혁신 경로의 단계, 방향, 속도.
  • 분기 매출 증가율, 매출총이익률 변화, 영업이익률, 잉여현금흐름과 계절성 비교.
  • 경영진의 반복 지표와 투자 → 채택 → 수익화 → 이익 → 현금흐름의 단절 지점.
  • 최초 경고, 확인 분기, 가장 강한 반대 증거와 판단 수정 조건.
  • 재투자율 및 투하자본수익률 계산, 공식과 기준, 데이터 부족에 따른 한계.

가치평가, 주가 예측이나 매매 조언을 자동으로 추가하지 않습니다.

02

권장 모델

AI 서비스 설정에서 모델을 직접 선택하세요. 스킬은 모델을 자동 변경하지 않으며 결과는 모델마다 다를 수 있습니다.

평가모델추론 강도
우선 권장GPT-6.1 solmedium 또는 low
현재 테스트에서 높은 기준 충족Opus5.5high
일관적이지 않지만 사용 가능Grok4.7 / Gemini 3.1 prohigh

위 권장 사항과 테스트 평가는 작성자가 제공한 것입니다.

03

설치 방법

  1. Skill 링크 받기

    비공개 그룹에서 Austin이 제공한 Skill 링크를 받으세요.

  2. 링크 붙여넣기

    로컬 AI 도구의 대화에 해당 링크를 붙여넣으세요.

  3. agent에게 설치 요청

    아래 설치 지시문을 붙여넣으세요. agent가 전체 스킬을 다운로드하고 압축을 풀어 설치하므로 로컬 파일 경로를 직접 입력할 필요가 없습니다.

가능하면 Codex로 시작하세요. 파일 다운로드, 로컬 파일 접근, 스킬 지원, 웹 검색 기능이 필요합니다. 선택적 계산에는 Python 3 표준 라이브러리만 필요합니다. Austin이 제공한 Skill 링크를 사용하면 비공개 GitHub 저장소 권한이 필요하지 않습니다.

이 대화에 붙여넣은 Austin이 제공한 Skill 링크에서 다운로드하고 압축을 푼 뒤 enterprise-operating-innovation-cycle 스킬을 설치해 주세요. VERSION을 먼저 읽고, 기존 설치가 있으면 로컬 수정과 보고서를 보존하면서 기존 위치만 업데이트하세요. 중복 설치하지 말고 설치 경로와 버전을 한국어로 알려 주세요.

설치 확인

enterprise-operating-innovation-cycle이 스킬 시스템에서 인식되고 버전이 0.2.11인지 확인한 뒤, EOIC로 SNPS의 최근 공시된 5개 분기를 한국어로 분석해 주세요.

일반 실적 요약이 아닌 실제 스킬 로딩을 확인해 달라고 요청하세요. 목록이 갱신되지 않으면 대화를 다시 열거나 도구를 재시작하세요.

04

다른 AI 서비스 설치

다른 도구에서도 Austin이 제공한 Skill 링크를 사용합니다. 비공개 그룹의 링크를 대화에 먼저 붙여넣고 해당 지시문을 붙여넣으세요.

Claude Code

Claude Code 대화에 Austin이 제공한 Skill 링크를 붙여넣고 다운로드와 설치를 요청하세요.

이 대화에 붙여넣은 Austin이 제공한 Skill 링크에서 다운로드하고 압축을 푼 뒤 해당 스킬을 Claude Code 개인 스킬 enterprise-operating-innovation-cycle로 설치해 주세요. 모든 참조 파일과 기존 로컬 수정을 보존하고 설치 위치와 VERSION을 확인해 주세요.
Gemini / Antigravity

Antigravity 대화에 Austin이 제공한 Skill 링크를 붙여넣고 다운로드, 설치 및 Antigravity Skill로의 변환을 요청하세요.

이 대화에 붙여넣은 Austin이 제공한 Skill 링크에서 다운로드하고 압축을 푼 뒤 해당 스킬을 Antigravity Skill로 설치하고 변환해 주세요. EOIC 분석 방법, 언어 규칙과 참조 파일을 유지하고 분석 요구 사항은 변경하지 마세요. 기존 로컬 수정을 보존하고 VERSION을 확인해 주세요.
Grok CLI

Grok CLI 대화에 Austin이 제공한 Skill 링크를 붙여넣고 다운로드와 설치를 요청하세요.

이 대화에 붙여넣은 Austin이 제공한 Skill 링크에서 다운로드하고 압축을 푼 뒤 enterprise-operating-innovation-cycle 전체를 ~/.grok/skills/enterprise-operating-innovation-cycle/에 설치해 주세요. VERSION을 먼저 읽고 모든 참조 파일과 로컬 수정을 보존하세요. 기존 설치가 있으면 중복 설치하지 말고 기존 위치를 업데이트하세요. 설치 위치와 버전을 알려 주세요.
05

스킬 시작

설치 후 대화에 EOIC를 입력하세요. 터미널 명령이 아닌 스킬 시작 문구입니다.

EOIC

별칭: 기업 운영 주기, 기업 혁신 주기, 기업 운영 및 혁신 주기.

미국 주식 종목 코드와 분기 수(4~6개 권장), 또는 시작·종료 기간을 입력하세요. 예: WING 6 quarters / WING 2022 to 2024/6.

SNPS 5 quarters로 답하거나 아래 전체 프롬프트를 사용하세요. 4~6개는 권장일 뿐 제한이 아닙니다. 기간이 없으면 질문하며 기본값은 6개 분기입니다.

명시한 언어가 우선이며 그다음 입력의 주된 언어를 따릅니다. EOIC나 종목 코드만 있으면 대화 언어를 사용하고 판단 불가 시 번체 중국어를 사용합니다. 비영어 용어는 첫 등장에만 영어 명칭이나 약어를 덧붙입니다.

06

사용 예시

일반 분석

EOIC SNPS의 최근 공시된 5개 분기를 한국어로 분석해 주세요.

혁신 집중 분석

EOIC Visa의 최근 8개 분기를 분석하고 혁신이 가속되거나 전환되었는지 판단해 주세요.

과거 분석

EOIC 2026-09-30 기준 WING의 최근 공시된 6개 분기를 분석해 주세요.

데스크톱에 저장

EOIC SFM의 최근 4개 분기를 분석하고 Markdown 보고서를 데스크톱에 저장해 주세요.

기간은 회계 분기를 선택하며 기준일은 당시 공개된 정보만 사용하도록 제한합니다. 기준일이 없으면 실행 당일에 공개된 정보를 사용합니다.

업데이트 및 사용 조건

v0.2.11

이 가이드는 0.2.11에 해당합니다. 실제 설치 패키지 버전은 폴더의 VERSION 파일을 확인하세요.

새 ZIP을 받았을 때

Austin이 비공개 그룹에서 새 Skill 링크를 제공합니다. 로컬 AI 도구의 대화에 새 링크와 아래 업데이트 지시문을 붙여넣으세요. 개인 보고서와 수정 사항은 보존하세요. 자동 업데이트 서비스는 없습니다.

이 대화에 붙여넣은 Austin이 제공한 새 Skill 링크에서 다운로드하고 압축을 푼 뒤 설치된 enterprise-operating-innovation-cycle을 업데이트해 주세요. 신구 VERSION을 비교하고 로컬 수정과 보고서를 보존하며 기존 설치 위치만 업데이트한 뒤 버전과 스킬 인식 상태를 확인해 주세요.
