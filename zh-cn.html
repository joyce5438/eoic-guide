企业营运与创新周期分析

从收到 ZIP 到完成第一份研究。

用多季财报和电话会议判断创新加速、减速、变现停滞或修复。收入增长和漂亮的利润率本身不代表创新成功。

开始安装 ↗

ZIP 由 Austin 在私人群组提供，本页不提供下载。

01

会得到什么

  • 整体营运与各条创新路径的阶段、方向、速度。
  • 多季收入季增、毛利率变化、营业利润率、自由现金流及季节性比较。
  • 管理层重复关注的指标，以及投入 → 采用 → 变现 → 利润 → 现金流的断点。
  • 最早警讯、确认季度、最强反证及可观察的改判条件。
  • 再投资率与投入资本回报率的计算、公式和口径，资料不足时明确列出限制。

不自动提供估值、股价预测或买卖建议。

03

安装方法

  1. 获取 ZIP 并解压

    从私人群组下载 Austin 提供的版本。Windows 使用“全部解压缩”；Mac 双击 ZIP。

  2. 找到技能文件夹

    找到同一层包含 SKILL.md、METHODOLOGY.md、VERSION 的文件夹。保留整个文件夹，不要只取 SKILL.md。

  3. 交给 agent 安装

    在支持本地技能的工具中打开或指定该文件夹，可附上文件夹或提供完整路径。将下方指令中的路径替换为自己的。

建议先用 Codex。工具需要本地文件读取、技能支持和搜索／浏览能力。可选计算仅需 Python 3 标准库。使用群组 ZIP 无需私有 GitHub 仓库权限。

请从“填入解压后技能文件夹的完整路径”安装 enterprise-operating-innovation-cycle 技能。先读取 VERSION；已有同名技能时，保留本地修改与报告，只更新原安装位置，不重复安装。完成后回报位置与版本，使用简体中文。

安装后确认

请确认 enterprise-operating-innovation-cycle 已被技能系统识别，版本为 0.2.11，然后使用 EOIC 分析 SNPS 最近五个已公布季度，用简体中文。

请 agent 确认实际加载了技能，而非仅做一般财报摘要。技能列表未刷新时，重新打开对话或重启工具。

04

更多 AI 服务安装方式

以下同样使用解压后的本地文件夹，不必提供私有 GitHub 网址。

Claude Code

在 Claude Code 打开技能文件夹或提供完整路径，再要求安装。

请从“技能文件夹完整路径”安装为 Claude Code 个人技能 enterprise-operating-innovation-cycle；保留全部参考文件和已有本地修改，确认安装位置与 VERSION。
Gemini / Antigravity

Gemini 用户可使用 Antigravity，打开或指定文件夹后要求安装、改写为 Antigravity Skill。

请将“技能文件夹完整路径”安装、改写为 Antigravity Skill，保留 EOIC 分析方法、语言规则和参考文件，不改变分析要求；保留已有本地修改，确认 VERSION。
Grok CLI

若使用的 Grok CLI／agent 支持本地技能，提供文件夹路径并要求安装。不同 CLI 支持不同，先由 agent 确认可用安装方式。

请先确认本工具是否支持本地技能；若支持，从“技能文件夹完整路径”安装 enterprise-operating-innovation-cycle，保留参考文件和本地修改，并确认版本；否则说明限制。
05

如何启动技能

安装后，在对话输入 EOIC。这是技能启动短语，不是终端命令。

EOIC

也可使用：企业营运周期、企业创新周期、企业营运创新周期。

请输入美股代码与季数（建议4～6季），或指定起止年月。例如：WING 6季／WING 2022到2024/6。

接着输入 SNPS 五季，或使用下方完整指令。4～6 季是建议，不是限制；未指定期间会先询问，“用默认”则选择六季。

明确指定语言优先，否则跟随主要输入语言；只有 EOIC 或代码时沿用对话语言，无法判断才用繁体中文。非英文术语首次附英文名称或缩写，后续不重复。
