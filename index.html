企業營運與創新週期分析

從收到 ZIP 到完成第一份研究。

用多季財報與電話會議，判斷創新正在加速、減速、遲滯或修復。營收成長不等於創新；漂亮利潤率也不等於創新成功。

開始安裝 ↗

ZIP 由 Austin 在私人群組提供，本頁不提供下載。

01

會得到什麼

  • 整體營運與各條創新路徑的階段、方向、速度。
  • 多季營收季增、毛利率變化、營業利益率、自由現金流，以及季節性比較。
  • 管理層重複追蹤的營運指標，與投入 → 採用 → 變現 → 利潤 → 現金流的斷點。
  • 最早警訊、確認季度、最強反證及可觀察的改判條件。
  • 再投資率與投入資本報酬率的計算、公式與口徑；資料不足時明列限制。

不自動提供估值、股價預測或買賣建議。

03

安裝方法

  1. 取得 ZIP 並解壓

    從私人群組下載 Austin 提供的版本。Windows 可用「全部解壓縮」；Mac 可雙擊 ZIP。

  2. 找到技能資料夾

    找到同一層包含 SKILL.md、METHODOLOGY.md、VERSION 的資料夾。保留整個資料夾，不要只拿 SKILL.md。

  3. 交給 agent 安裝

    在支援本機技能的 AI 工具中開啟或指定該資料夾；可附上資料夾或貼上完整路徑。將下方指令中的路徑換成你自己的。

建議先用 Codex。你需要能讀取本機檔案、支援技能與搜尋／瀏覽的工具；可選計算僅需 Python 3 標準函式庫。使用私人群組 ZIP 不需取得私有 GitHub 儲存庫權限。

請從「填入解壓後技能資料夾的完整路徑」安裝 enterprise-operating-innovation-cycle 技能。先讀取 VERSION；已有同名技能時，保留本機修改及報告，只更新原安裝位置，不重複安裝。安裝後回報位置與版本，使用繁體中文。

安裝後確認

請確認 enterprise-operating-innovation-cycle 已被技能系統辨識，版本為 0.2.11，然後使用 EOIC 分析 SNPS 最近五個已公布季度。

讓 agent 確認載入的是技能，而不是只做一般財報摘要。如果技能清單沒有刷新，先重新開啟對話或重啟工具。

04

更多 AI 服務安裝方式

以下同樣使用解壓後的本機資料夾，不必把私有 GitHub 網址貼給 agent。

Claude Code

在 Claude Code 開啟技能資料夾或提供完整路徑，再要求安裝。

請從「技能資料夾完整路徑」安裝為 Claude Code 個人技能 enterprise-operating-innovation-cycle；保留所有參考檔案，已有版本先保留本機修改，並確認安裝位置與 VERSION。
Gemini / Antigravity

Gemini 用戶可使用 Antigravity，開啟或指定技能資料夾後要求安裝、轉寫為 Antigravity Skill。

請將「技能資料夾完整路徑」安裝、轉寫為 Antigravity Skill；保留 EOIC 分析方法、語言規則及參考檔案，不改變分析要求。已有版本先保留本機修改，安裝後確認 VERSION。
Grok CLI

若你使用的 Grok CLI／agent 支援本機技能，提供技能資料夾路徑並要求安裝。各 CLI 的技能支援不同，先由 agent 確認可用的安裝方式。

請先確認目前工具是否支援本機技能；若支援，從「技能資料夾完整路徑」安裝 enterprise-operating-innovation-cycle，保留參考檔案與本機修改，並確認版本；若不支援，請說明限制。
05

如何啟動技能

安裝後，在對話輸入 EOIC 即可。這是技能啟動短語，不是終端機命令。

EOIC

也可使用：企業營運週期、企業創新週期、企業營運創新週期。

請輸入美股代號與季數（建議4～6季），或指定起訖年月。例如：WING 6季／WING 2022到2024/6。

接著輸入 SNPS 五季，或直接用下方完整指令。4～6 季是建議，不是限制；未指定期間會先詢問，指定「用預設」則取六季。

明確指定語言優先，否則跟隨主要輸入語言；只有 EOIC 或代號時沿用對話語言，無法判定才用繁體中文。非英文術語首次附英文原名或縮寫，後續不重複。

更新與授權

v0.2.11

本頁對應版本 0.2.11；安裝包的實際版本以資料夾內 VERSION 為準。

收到新版 ZIP 時

新版由 Austin 在私人群組提供。下載、解壓後，將新資料夾路徑交給 agent，更新原安裝位置；不要直接覆蓋自己的報告或修改。這個技能沒有自動更新服務。

請從「新版技能資料夾完整路徑」更新已安裝的 enterprise-operating-innovation-cycle。先比較新舊 VERSION，保留本機修改與報告，只更新原安裝位置，完成後確認版本與技能辨識狀態。
